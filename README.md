# BudgetWise – Personal Finance and Spending Analysis

## 📌 Project Overview
BudgetWise is a data analytics project that analyzes personal financial transactions to understand spending patterns, transaction behaviour, payment methods, and spending trends. Interactive Power BI dashboards present the findings in a clear and user-friendly format.

## 🎯 Project Objective
The main objective of this project is to analyze financial transactions, identify major spending categories and high-value transactions, understand spending trends, and provide data-driven insights to support better budgeting and financial decision-making.

## 🛠️ Tools & Technologies
- **Python** – Data cleaning and Exploratory Data Analysis (EDA)
- **Pandas** – Data manipulation and preprocessing
- **Matplotlib & Seaborn** – Data visualization
- **Power BI** – Interactive dashboard development
- **DAX** – Calculations and KPI measures
- **GitHub** – Project documentation and version control

## 🧹 Data Cleaning & Preprocessing
